### Query execution: simplest candidate to independently validate

1. Authenticate Owner on Java API; validate bounded user question, explicit source-ID/selected-revision/group roster for Ideaverse canon mode (deny absent/stale roster), small client-supplied history. Generic Markdown query may use all eligible approved indexed sources. **No raw file paths** as authoritative selector or implicit query-time filesystem discovery. See [identity/selection contract](query-consumer-lifetime-and-selection.md#canonsource-selection-contract-p19-pr-03).
2. Resolve only `CURRENT`, consented whole-file `.md` generations and every contributing dependency; admit a **durable active-reader exclusion under the same authoritative sorted source guards at C_A** (Owner-approved prospective design). For each candidate chunk/span, intersect **actual contributing source IDs + revisions** with query evidence roster **before ranking**; approved indexed dependencies alone are insufficient. Where mixed-source chunk spans cannot be attributed safely, discard the whole chunk. Do not emit count/rank/alias/metadata before this proof. Internal private markers of approved WHOLE_FILE external Markdown are **not** source-level denial. No blanket permission from historical PUBLISHED state.
3. Embed query using existing pinned **384-dimensional** model; start with scoped exact pgvector ranking with safe top-K + excerpt/context-size limits. If acceptable, do **not** add FTS/hybrid/reranker. Do not trust heading/alias metadata as authorization.
4. Assemble compact source passages with file/heading/real locators, preserved exact names, capped request budget and source identities; hard-separate instruction-bearing user/Markdown from system policy. Source snippets are reference data, not executable tool commands.
5. A **pinned local CPU** generation model produces a non-streamed answer; apply deterministic output size/format/citation-ID validation and **conservatively** abstain when support is missing. Automated citation-ID validation is not a full semantic entailment prover; human/independent sample QA remains necessary.
6. **Chosen prospective contract:** retain committed active source/dependency reader exclusion throughout retrieval/model/response write; reprove current permission at end, do not release until after actual server-side **non-streamed HTTP emission C_E**, positive stop/context disposal and guarded terminal release C_RL. A conflicting normal source mutation returns 409 with no requested commit; cancel-first, incident deny and unknown/restart recovery are explicit. No SQL transaction spans LLM inference; last-check-only and TTL releases are prohibited. This design is **Owner-approved** under [P19-OD-01 option A](owner-decision-p19-reader-exclusion.md); exact source/migration feasibility, independent re-review and separate implementation authorization remain mandatory. See [complete protocol and R01–R10](query-consumer-lifetime-and-selection.md).
7. Return answer + grounded citations + explicit partial/conflict/abstention indicators; no durable chat content or raw prompt/answer log. Request failures, model OOM, timeouts and authority uncertainty deny disclosure, sanitize errors and release model/request resources.

**Do not implement from these numbered steps alone.** The exact source-use lifetime mechanism, authenticated API contract and model process design require Codex pre-handoff feasibility review before an executable handoff.
