## How to inspect each record

1. Read the exact original Markdown and its separate line-number guide. Source copies are `.txt`
   to keep embedded syntax inert. Compare the full SHA-256 with [source-hashes.json](source-hashes.json).
   Exact UTF-8 source bytes, including CRLF, are preserved in those files; the line guide is only a guide.
2. Read the expected interpretation. For interpretation records, compare original official HTML,
   original gold, current overlay and independent rationale. For the seven adjudications, explicitly
   decide whether the documented current interpretation represents the source under frozen D17.
3. Inspect actual chunks, node roles/parents, table cells, properties and native HTML trees. Expand
   the details panels as needed. Every record links a full JSON snapshot; no structural entries or
   cell rows are sampled. Inline/native derived nodes may honestly use containing-source context.
4. Check source/revision, exact original character and line spans, block/cell roles, dependency
   edges and supplied bindings. Characters are zero-based with an exclusive end; lines are one-based.
   Selected Child/Grand views deliberately show only approved selectors within full original sources.
   Omitted unselected child sections are explicit, not silent root loss. Each root must be complete.
5. Read exact machine differences and potential ambiguities. An empty diff or matched projection
   is machine evidence only. Question the expected interpretation as well as actual output; source
   equality alone does not prove structural correctness. Comment, code and native HTML markers must
   not become child authority. Unapproved outside embeds and unsafe material require whole-root denial.
6. Enter exactly one human judgment and a reason. **ACCEPT** means the case is faithful under D17;
   **REJECT** means describe the wrong text/structure/authority/locator or expected label; **UNCERTAIN**
   means identify the unresolved question. Rejecting or questioning a case does not authorize a fix.
7. Complete all twelve checklist rows after reviewing their referenced books. Keep missing, REJECT
   or UNCERTAIN judgments pending reconciliation. Do not use overall approval to fill unreviewed rows.
