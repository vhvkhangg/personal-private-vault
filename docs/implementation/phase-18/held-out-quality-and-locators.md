# Phase 18 P17-N1 — Independent ingestion/OCR quality and source-locator oracle

**Status:** Mandatory **future implementation acceptance** under previously accepted [P17-N1](../phase-17/benchmarks-and-acceptance.md#8-p17-n1--held-out-evaluation-before-first-affected-capability-acceptance). This document defines the *test protocol*, not fabricated measurements or automatically met thresholds. One small local ingestion-only evidence set is enough; no LLM judge, retrieval, answer or recommendation metrics in Phase 18.

**2026-10-18 applicability:** [ADR-0022](../../adr/0022-phase-18-immutable-snapshot-whole-file-consent-no-change.md) is `OWNER_APPROVED / CANONICALLY_SYNCHRONIZED`; runtime remains `STOPPED / INCOMPLETE / NOT_VERIFIED`. External S uses WHOLE_FILE plus exact S/R/original-byte SHA-256/length and structural roles, without per-field privacy approval/projection. Frozen Vault field/denial rules remain unchanged. Private/NSFW/hidden/comment/property/frontmatter content is positive authorized in-file data after a valid file grant; independent external children still require independent grants.

## Split preparation, immutability and provenance

1. **Before engine/model/chunk tuning**, write one sanitized versioned manifest (JSON/CSV fixture inventory) with two immutable groups: `development` (may tune) and `held_out` (never tune). Freeze manifest SHA-256, file/source content hashes, label revision, pipeline/config revision and selection date. Use only owner-approved, public-safe or synthetic data; never commit real private documents. Evaluation local offline only.
2. **Split by document family/source group**, not by chunk, page, question, file variant, scan or OCR output. Place translations, scan/native versions, table exports, near-duplicates, and the **entire Obsidian transclusion/dependency closure** in the same split. Check by canonical source-group IDs plus duplicate/near-duplicate content hashes; independently verify `dev ∩ held_out = ∅`, no duplicate/cross-linked source groups and no train/test tuning feedback leakage.
3. Provide reviewer-visible **reference labels**: exact authorized characters/tokens including Vietnamese accents and Simplified/Traditional Han, reading order, headings, table/merged-cell relationships, independently approved child S/R, whole-file source authority/structural element role (actual field grants for Vault), and required span/box/page/cell/paragraph/container locator values. Human reviewer adjudicates ambiguous scans/boxes with a written rule and second check for acceptance-critical ambiguity; count disagreements explicitly. Supported hidden/comment/property material needs positive coverage labels; no silent privacy omission.
4. Label each source group with supported `md/Obsidian`, `txt`, `docx`, `pdf-native`, `pdf-scan`, `pdf-mixed`, `xlsx`, `xls` and language slices `vi`, `en`, `zh-Hans`, `zh-Hant` where applicable. Cover all introduced formats and all four OCR language groups, native/scan/mixed PDFs, table/merged cells, security adversaries, failed/corrupt sources and deliberately absent mandatory locators. Do **not** demand full Cartesian format × language coverage for meaningless combinations; record why any cell is N/A.
5. At evaluation, output a reproducible per-slice ledger: tested **groups/documents/pages/blocks/tables/cells**, passing, error, materially failed file, skipped, pending/unrun, reason, dataset/config/model/engine hashes, commands and exit codes. Denominator includes attempts and missing results; do not drop failed pages or cherry-pick published chunks. Changes to test data/config after evaluation require a new version and renewed independent held-out run.

## Locator oracle (no fictional provenance)

| Source | **Mandatory** for every published element/chunk | Optional (warning when legitimately unavailable; never fabricate) |
| --- | --- | --- |
| TXT | Exact S/R/version, WHOLE_FILE/element role and original-byte digest, validated original **character span or line range** with stable decoded encoding mapping and excerpt correspondence. | Human-friendly heading/section when source has none. |
| Markdown/Obsidian | Exact S/R/version, WHOLE_FILE/element role/original-byte binding, stable original **line/span** and heading scope, exact child source/revision/edge for transclusions. Frontmatter/comments are in scope. | Block ID, alias display or heading slug when absent. |
| DOCX | Exact S/R/version/role/original-byte binding, stable **paragraph / table / row / column** address from original DOCX structure and excerpt alignment, including supported hidden content. | Rendered page/geometry that DOCX does not reliably own. |
| PDF text/scan/mixed | Exact S/R/version/role/original-byte binding, **1-based source page**, coordinate system/orientation and actual **bounding box** for extracted/OCR blocks and materially attributed table cells; containment, reading order/table/merged-cell ancestry. No guessed boxes. | OCR confidence if unavailable; display-only section title/tag. |
| XLSX/XLS | Exact S/R/version/role/original-byte binding, workbook, **worksheet + A1 cell/range**, headers, merged-cell relationships and original value correspondence. Supported hidden sheets/rows/cells are within the grant, not excluded for field consent. | Rendered pagination or non-existent table name. |
| Genuinely non-page/cell-located property/comment/internal object | Discriminated original structural variant: stable original **container part + property key / object ID / comment ID**, anchor where applicable, bound to exact S/R and original-byte digest. Exact content/excerpt-to-object correspondence is mandatory. | A page/box/line/A1 coordinate that the source does not own must be absent, never invented. |

The structural variant is narrowly additive for newly admitted internal content with no page/cell location. Actual page-/cell-located or anchored content retains its required geometry and structural attribution; a comment ID cannot conceal a real page/cell anchor. Exact-byte storage removes only projection-to-original mapping, not parser/OCR-normalization/excerpt-to-original alignment. Missing mandatory attribution or material supported extraction fails the file. Whole-file permission does not imply arbitrary binary headers/code must become embeddings; report coverage/material omissions truthfully without a privacy-filter loophole. Formulas/macros/scripts/remote resources remain unexecuted/unfetched.

A **mandatory** unknown/misaligned/source-invented locator or unapproved attribution is a **material file failure** and **no new generation** for that file. Optional absent metadata is a typed warning **only** if every mandatory source/field/path/version/child/geometry/structure proof remains correct. Never use a confidence threshold, inferred page number, guessed A1 range or a disclaimer to waive mandatory provenance. If a particular PDF extractor cannot produce required boxes, **choose a capable pipeline or fail the file**, not silently loosen scope.

## Quality/admission oracle

- **Deterministic hard failures (zero tolerance):** denied source/field exposure; unauthorized child or dependency; fabricated/missing mandatory locator; wrong source version/field policy; lost material page/table; material row/column/merged-cell mismatch; broken character encoding/reading order that makes factual content unusable; nonfinite/wrong-dimension vector or unverified staging/source fence. Such a file has no published replacement; security/fencing failures can abort the entire job per D18-A.
- **Nonmaterial warnings:** bounded OCR uncertainty in known characters, genuinely optional metadata unavailable, or faithfully preserved complex formatting whose semantic meaning is unchanged. Warning records a sanitized code and affected locator ID; it does not imply content completeness or permit mandatory proof gaps.
- **Measured quality:** development/held-out character error rate (CER) or equivalent labeled text comparison per language; reading-order inversions, page/block coverage, table row/column/merged-cell mapping accuracy, mandatory-locator match rate, file rejection sensitivity for seeded critical errors. Record numerator and denominator; human label/final adjudication takes precedence over uncalibrated engine confidence. One targeted OCR retry (at most once per failed region), with initial/retry results attributed; avoid duplicating native text.
- **Heuristic honesty:** runtime probes can identify low native text density, OCR low confidence, suspicious reading-order/table omissions and missing locators, **not guarantee detection of every semantic OCR error**. Record known blind spots; held-out labeled evaluation bounds observed risk. Require no demonstrably material misread among **published held-out files**, 100% mandatory-locator/source-denial checks in tested negative fixtures, and finite explicitly measured per-slice quality defaults selected from development data **before** held-out acceptance. Do not invent a target CER/WER or fixed corpus quota in preparation. If chosen defaults cannot support the scope, fail the gate and request a bounded owner decision; never silently relabel important errors as warnings.
- **Separation:** candidate/model comparison and token/chunk tuning use development only; held-out run once after freezing engine/config hashes, with full errors/skips/pending. A failed held-out result is a failed gate until reviewed correction and fresh independent evidence. No local LLM judge introduced, so judge calibration is N/A. Retrieval/no-answer/QA/recommendations remain Phase 19/20.
