## Focused test plan and evidence

- **Pure unit tests:** HN article URL selection, same URL/different IDs, latest-time/tie-ID winner, missing article URL skip, changed URL, jobs/dead/deleted/null, HTML-as-data, HN submission UTC time, rank at capture, invalid JSON, finite caps/limit/timeouts and per-source admission using fake transport.
- **Feed + Postgres integration:** article-centric upsert over real unique keys, preexisting `hn:old` external ID by-hash replacement, repeated refresh, selected-representative change, source-type and disable races with deterministic barriers and full rollback of rows/timestamps, no lock held over fake HTTP. Reuse accepted `FeedIngestionConcurrencyTest`, `FeedIntegrationTest`, and fresh provider-specific focused tests; rerun only source-applicable adjacent cases unless the change warrants more.
- **Web/OpenAPI tests:** authorized/unauthorized manual refresh, source changed/disabled safe error, actual saved **article URL**, truthful response counters, `GET /radar` no network, enabled-HN-only fixed-24h bounds/filter/order/null/future times, source provenance and existing `FeedWebIntegrationTest`, `SavedResourceInboxWebIntegrationTest`, `OpenApiRouteInventoryIntegrationTest` coverage.
- **Adversarial outbound negative:** configured external-URL bait, redirect-to-private-address, loopback/cloud metadata/DNS-trust tests through a fake resolver/transport. Do not make real requests to unsafe destinations, disable outbound controls, or access private user content.
- **Budget/environment:** use the accepted `scripts/run-bounded-command.py`, normal profile capped to **300 seconds per focused command**, unique ignored receipts. Whole-suite/real-provider smoke only if separately justified/authorized; no `mvn clean verify` blanket run while archived QA isolation must be preserved. Do not start S19-2/C2/native models.

Review must report PASS/FAIL/NOT_RUN/NOT_VERIFIED accurately for each case plus applied 29-category coverage. A missing mandatory gate blocks `READY_FOR_OWNER_COMMIT` for implementation. Material contract change → Owner decision, not guessed approval. Critical/High/Medium follow normal bounded remediation policy; LOW/INFO are recorded under current feature-review policy but **the later final non-RAG audit must resolve all actionable severities including LOW/INFO**, not auto-defer them into frontend.
