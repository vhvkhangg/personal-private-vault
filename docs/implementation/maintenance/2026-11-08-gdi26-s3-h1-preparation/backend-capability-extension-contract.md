**Status: PREPARATION, OWNER/INDEPENDENT REVIEW PENDING.** This document supersedes the **ambiguous candidate alternatives** in the earlier v0.3 preparation; the prior proposals remain in the attached historical review, not operative choices. It adds **no implementation authorization**. Baseline main: `cba57541e4f1fa35a2d799082766f9cb600bea8d`.

- **PH-02 / authority, schema, routes:** [specific contract](h1-b-authority-schema-api-contract-v0.4.md): one durable Drive-owned `drive_child_folder_intents` registry, nullable parent ID in existing upload intents, prospective **V27** and Portability security exclusion, exact five new routes, exact first-level child proof and same-action reconciliation. S2 root-only routes retain semantics and history.
- **PH-03 / search and continuation:** [selected complete-scoped algorithm](h1-search-and-cursor-contract-v0.4.md): app-marker-limited Drive enumeration, server Unicode-NFC substring filtering, type/local-date semantics and source-counted 8-call-per-request bound (2 root + 1 list + ≤5 child proofs), provider pages ≤5 and **no buffered candidate rows**; missing or unfinished results cannot be called complete.
- **PH-04 / preview:** [fixed thumbnail trust/fallback contract](h1-thumbnail-security-contract-v0.4.md): current file/root/child proof, exact allowed origin and no redirects, bounded safe-image proxy, fallback where unsupported/untrusted. No universal PDF/DOCX thumbnail guarantee.
- **Quota and UI:** exact current-slot `GET /storage-quota`; `storageQuota.usage` is all-service account usage, `usageInDrive` is Drive usage, `limit` may be absent/pooled. No fabricated PPV root folder size, file counts or percentage.
- **Business boundaries:** D25=A **one child level only**, no adopted/nested/external Drive folder, batch local-directory upload, file mutation CRUD, broad Google Picker, extra scope, RAG, Media S3 or deployment. Drive/Drive Files/Feed OFF by default.

Review contracts **together**. If the real API violates selected guarantees, Codex must return `CHANGES_REQUESTED` and identify the exact Owner-visible tradeoff rather than weaken semantics.
