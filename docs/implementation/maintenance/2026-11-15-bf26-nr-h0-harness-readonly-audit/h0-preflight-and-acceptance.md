## R. Separate independent H0 report review

Read the actual five H0 reports, complete file ledger, code references and selected safe raw receipts. Requalify H0 entry SHA, test versions and scenario classifications; replay a *small, risk-based set* of safe cases in **the reviewer's own environment** if authorized. Do not assume author model differs, or that second Codex session eliminates correlated error. Provide findings `H0-FR##` with exact paths, independent challenge and finite next decision.

Review verdict: `H0_ASSESSMENT_ACCEPTED / OWNER_H1_DECISION_REQUIRED`, `H0_CHANGES_REQUESTED` (report/evidence correction under read-only scope only), or `BLOCKED_H0_REVIEW`. Independent reviewer may not implement H1 or approve an H1 allowlist; Owner grants exact H1 paths only after considering H0 report. H0 assessment acceptance **does not certify effective safety of an untested hook/model**.
