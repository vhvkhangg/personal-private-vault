## Lowest-complexity design principle

Retain the **one data Owner** and shared business tables. Implement **two fixed credential/access profiles**, not two human users or tenants. Keep the existing Owner password as the **Private credential**; provision a second **Public credential** through an authenticated Private operation; do not copy plaintext or duplicate the Private password hash into another authoritative table. Bind profile **and server-revocable session generation** to the tokens. Enforce resource visibility before query pagination/serialization/mutation/streaming. Deny Public access to any unclassified personal or derived path. The security design is *future scope for review*, not approved production code.
