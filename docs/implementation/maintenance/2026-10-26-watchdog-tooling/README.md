## Runtime truth and measured limits

- **B1:** Ordinary commands have a 300-second execution deadline. Extended execution up to 2100 seconds is permitted only for approved, guarded large/complex verification shapes. At 300 seconds without observable output/progress, take a bounded health/progress diagnosis; silence alone is not a confirmed hang. Record bounded shutdown grace and limits separately. Only the owned process tree may be terminated; unavailable descendant verification must not produce a false PASS. Fresh evidence paths must not overwrite existing `logs/` files. Details and acceptance are in [B1 contract](b1-executable-handoff-2026-10-26.md); review evidence is not a proof of every possible native operation, or actual 2100s host duration.
- **B2:** `model_verbosity=low` does not hide every tool-rendered event. Codex Git guards were independently tested using **Codex CLI 0.164.0 on Windows from a trusted repository root with native hooks loaded**. Startup from scoped subdirectories, untrusted/skipped hooks, arbitrary shell/alias/encoded commands, other CLI versions/platforms, GUI/connector paths and universal interception are not certified. Native Antigravity `force_ask` withholds permission overrides but does not guarantee a human prompt or hard denial under every ambient policy. See [B2 independent review](reviews/2026-10-26-b2-independent-takeover-attempt-1-final-review.md).
- **Privacy and retained evidence:** B2 removed the optional hook audit producer; the accepted B1 private output/receipt capture remains. Preserve all previously existing and newly accepted `logs/` files. No historical failed/absent evidence is converted to PASS.
- **Historical preparation only:** The originally observed runner with 1200/2100-second fixed wait and the original parser-only native-hook tests are recorded in the [independently accepted preparation review](reviews/2026-10-26-maintenance-b-independent-pre-handoff-review.md).
