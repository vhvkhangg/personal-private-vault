- empty backend Java package skeleton

- root repository hygiene files (`.gitignore`, `.gitattributes`, `.editorconfig`)

- Spring Boot/Maven implementation scaffold
- application code
- tests
- frontend implementation
- RAG implementation
- deployment infrastructure
- AGENTS/skills/hooks (planned in a later repository-governance step)
